# Code of Conduct

This project follows a short, practical conduct bar.

## Expected

- Be respectful in issues, reviews, and discussion.
- Assume good intent; disagree with ideas, not people.
- Do not share private session data, client matter, or API keys.

## Not welcome

- Harassment, hate speech, or personal attacks.
- Publishing secrets or private transcripts.
- Knowingly submitting malware or exploit payloads.

## Enforcement

Maintainers may hide comments, close PRs, or block contributors that violate this document. Report conduct issues through GitHub privately when possible.
